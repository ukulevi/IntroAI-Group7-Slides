# HW3 — Class Scheduling using Genetic Algorithm

Thư mục chờ cho bộ slide thuyết trình **Homework 3** (`CO3061` — Nhóm 7 · CC01).

## Khi sẵn sàng soạn slide HW3:
1. Thêm `main.tex`, file theme `.sty` (có thể kế thừa từ `hw1/hw1_hud_theme.sty` hoặc `hw2/hud_theme.sty`), ảnh minh họa vào `hw3/images/`, và kịch bản nói vào `hw3/script_short_en.md`.
2. Mở `.github/workflows/build-slides.yml`, thêm `hw3/**` vào trigger `paths`, thêm output `hw3` vào job `detect`, và nhân bản job `build-hw3` để GitHub Actions tự động biên dịch PDF + đính kèm vào Release `latest`.
